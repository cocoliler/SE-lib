# FlowStudio 前端任务画布

需要 Node.js 22.12 或较新的兼容版本。在 `frontend` 目录运行以下命令，访问 Vite 输出的本地地址。

```powershell
npm ci
npm run dev
```

`npm run build` 会检查 TypeScript 类型并构建静态资源。

1. 在画布上方填写项目需求，或点击「填入示例需求」。空白需求无法加载计划。点击「加载示例计划」会使用固定的 TEST 任务「整理需求 → 起草方案与测试」，已编辑的画布会先请求确认。
2. 点击节点或任务列表，在右侧查看任务 ID、名称和上游依赖。
3. 点「新建任务」，从上游节点右侧端口拖到新任务左侧。重复连接、自环和循环依赖会被拦截，画布底部会说明原因。右侧依赖列表可以移除连线。
4. 拖动节点或修改名称后尝试刷新，浏览器会在允许的情况下提示有未保存的修改。取消刷新并点「保存草稿」，再次刷新应恢复同一浏览器中的需求、计划与坐标。旧草稿仍可打开，需求初始为空。

计划数据与坐标分开存储。示例采用 Python 原型的 `tasks[].{id,title,depends_on}` 结构。当前页面仅编辑本地 TEST 草稿，团队接口确定后由 T09 对接真实审批与运行事件。
