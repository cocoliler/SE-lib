# FlowStudio 前端任务画布

需要 Node.js 22.12 或较新的兼容版本。在 `frontend` 目录运行以下命令，访问 Vite 输出的本地地址。

```powershell
npm ci
npm run dev
```

`npm run build` 会检查 TypeScript 类型并构建静态资源。

1. 初始 TEST 计划包含「整理需求 → 起草方案与测试」。点击节点或任务列表，在右侧查看任务 ID、名称和上游依赖。
2. 点「新建任务」，从上游节点右侧端口拖到新任务左侧。重复连接、自环和循环依赖会被拦截。右侧依赖列表可以移除连线。
3. 拖动节点或修改名称后点「保存草稿」。刷新页面应恢复同一浏览器中的计划与坐标。

计划数据与坐标分开存储。示例采用 Python 原型的 `tasks[].{id,title,depends_on}` 结构。当前页面仅编辑本地 TEST 草稿，团队接口确定后由 T09 对接真实审批与运行事件。
