# 产品需求

正式定位见[产品定位](PRODUCT_POSITIONING.md)，验收需求见[需求规格](REQUIREMENTS.md)，交付顺序见[首版范围](MVP_SCOPE.md)。

工作台服务于软件需求到设计验证。设计视图输入和修订规格、请求 Planner、编辑候选图并确认。执行视图追踪固定快照、审批、取消、成果和异常，验证视图展示规则检查、Reviewer 缺陷、修订及最终报告。三个视图共用工作流版本和任务标识，草稿和运行结果各自持久化。

主案例为学生选课管理系统。用户输入学生、课程容量、时间冲突和选退课等约束，得到需求、架构、数据库、API、开发任务和测试方案。独立任务并行后汇聚，下游须读取可追溯的上游成果。用户可批准一次定向修订。案例与证据要求见[验收](../testing/ACCEPTANCE_TESTS.md)。
