# 产品定位

**FlowStudio：基于多 Agent 的智能任务分解与可视化协同编排系统的设计与实现**

FlowStudio — Visual Multi-Agent Task Planning and Orchestration Platform

面向设计与开发团队。把复杂软件规格转换成可编辑任务图，确认后由专业 Agent 产生需求、架构、数据库、API、开发计划和测试方案，通过独立审查形成验证报告。首个案例为学生选课管理系统。领域知识放在规格、提示词和成果 Schema，编排层负责通用依赖、执行、数据绑定和审计。

专业性体现在可验证的计划、真正的分工与成果消费、受控执行和结果追溯。首版采用内置角色、一个模型适配器和 Windows 本地运行。完整自主编程、通用应用市场、商业运营、云部署和实时多人编辑排除。工具接口保留代码检查和受限文件操作的扩展点。
