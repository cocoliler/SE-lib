# 首版范围与交付门槛

调整方案待团队评审。首版实现 R01–R08，以学生选课管理设计串起结构化规格、计划、画布、真实执行与验证。

| 阶段 | 范围 |
|---|---|
| 串行联调 | 复用现有画布及 CLI 校验思路，接通网页从规格到审查的串行路径。允许暂用轮询 |
| P0 正式验收 | 固定 LangGraph 主图，单活动 run、并发上限 2、初始计划确认、真实 SSE 补发、跨角色成果传递、一次并行汇聚、取消和一次人工批准的定向修订 |
| P1 | 自定义 Agent、并行优化、通用局部重规划和重试、历史回放、成本管理、模板、检查点跨重启恢复 |
| P2 | RAG、MCP、长期记忆、受限代码 Agent 与工具发现 |
| 排除 | Docker、云或分布式部署、商业功能、多租户、实时多人编辑、完整自动编程 IDE |

Worker 使用内置 Research、Architect、Planning 与 TestDesign 角色。至少三种独立职责真实调用，完整案例覆盖全部角色与 Reviewer。一个模型连接可服务多个隔离的角色。Research 首版读取项目资料，没有检索权限时标注来源是输入材料。最多一次批准后的定向修订属于 P0，通用自动重规划后置。启动时将上次未结束 run 标为 FAILED 并记录中断，保留已落库成果。正式验收不以串行联调替代。
