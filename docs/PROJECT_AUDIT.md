# 现状差异与迁移
审计基线是本地 main 的 58790d6，独立 CLI 原型分支的 1b9b017，以及工作区未提交的首版提案。

| 已有证据 | 新要求 | 满足度与缺口 | 处理 | 优先级 |
|---|---|---|---|---|
| frontend/src/main.tsx 自由文本和固定示例 | 结构化规格保存和修订 | 部分，缺字段与后端 | 保留面板，新增规格表单 | P0 |
| frontend/src/plan.ts 的 id/title/depends_on | 带角色、产物绑定、验收项的任务图 | 部分，只有图编辑 | 增共享 Schema 与画布适配 | P0 |
| React Flow 已有注释、平移、布局、PNG、本地草稿 | 设计、执行、验证三视图 | 设计部分已实现，执行与验证待做 | 保留画布工具，新增真实运行投影 | P0 |
| 独立 CLI 的顺序执行、TEST 角色、SQLite、REAL 入口 | 专业角色协作、汇聚、人工控制和审查修订 | TEST 曾运行，REAL 未验收，无并行和网页后端 | 复用校验和适配思路，新增编排 | P0 |
| main 无 backend 或跟踪的自动化测试套件，前端曾作 Chrome 验证 | 事件、持久化和可复现测试 | 后端仅设计 | 新增接口、事务、测试和证据 | P0 |
| 已有任务分支和六人分工 | 3–5 人也可开展 | 原部分任务所有者不一致 | 统一负责人，提供兼任办法 | P0 |

迁移顺序为契约 → 画布适配 → CLI 逻辑抽取 → API 联调 → 并行和修订 → REAL 验收。旧浏览器草稿保留；导入后补齐规格与角色才能确认执行。CLI SQLite 保留为原型证据，正式数据库采用新路径。
