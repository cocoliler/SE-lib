# UI/UX设计系统

## B 前端已实现的编排页

采用参考截图中的 Dify 布局：浅色点阵画布作为工作区，紧凑的白色节点用曲线箭头表示任务依赖。顶部集中放置草稿状态、TEST 标识、「项目需求」和「保存草稿」。选中节点才在右侧显示详情，点击空白处或关闭按钮可还原全宽画布。窄屏下详情移到画布下方。参考 [Dify 工作流编辑器](https://github.com/langgenius/dify/blob/main/web/app/components/workflow/index.tsx)。

「项目需求」通过独立面板按需打开，参考 [n8n 将画布和配置区分开](https://github.com/n8n-io/n8n/blob/master/packages/frontend/editor-ui/src/app/components/WorkflowCanvasHostBody.vue)的思路。打开时聚焦输入框，可手动输入或填入示例。按 Esc 或点「返回画布」保留当前输入。空白需求无法加载计划，替换现有画布前先确认。页面标明 TEST 模式使用固定示例任务。

左侧浮动工具栏依次提供新建任务、添加注释、选择模式、手形平移、整理节点、导出 PNG 和任务列表。当前模式有选中态，图标按钮提供文字提示。注释用浅黄色卡片，点击后可在右侧编辑或删除。底部反馈连线错误、保存结果和导出状态。

## 完整产品设计目标

首版工作台以设计、执行、验证三视图承载流程，保留已实现画布。设计视图新增结构化规格和候选确认；执行视图展示真实任务和审批；验证视图追溯证据与修订。详见[执行可视化](EXECUTION_VISUALIZATION.md)。以下尺寸为演进目标。

桌面Web，建议1440×900；最低1280×720时左右面板可折叠。顶部56px：项目/计划名、保存状态、REAL/TEST、校验、审批/运行。左栏240px：Agent库与任务搜索；右栏360px：属性/输入输出/权限；底部可调时间线240px；中央无限画布。运行详情抽屉宽480px，可切到独立监控页。

页面：工作台（最近计划/待审批/失败）；编辑器；Agent库；模型与工具设置；运行历史/成果。创建空状态提供输入目标和手动编排两入口；规划中显示阶段及取消，不用虚构百分比；失败显示字段定位与重试次数；无Key显示TEST和配置入口；断线保留最后确认状态加时间，不标为失败。

设计tokens：背景#F6F8FB、面板#FFFFFF、正文#182230、次文字#526176、边框#D7DFEA、主色#315EFB、成功#15803D、警告#A16207、失败#B91C1C。状态同时用图标+文本，不能仅用颜色。字体Segoe UI/微软雅黑，正文14px/20px，标题18/26，代码Consolas。8px间距基准，按钮32/40px高，输入36px，圆角8px，焦点2px清晰描边；对比度与键盘可达性在实现中验收。

节点宽280px、最小高160px：角色图标与名称、状态、两行任务摘要、model、耗时/token、错误角标。输入/输出handle左右分布；选中蓝边、执行进度条只表示已知步骤，不捏造模型思考进度。依赖实线灰箭头，handoff紫色虚线带交接标签，数据蓝色点线并显示字段；可分别隐藏，图例固定可见。

审批展示计划diff、任务/工具授权、模型及预算、验收标准；按钮“批准此版本”“退回修改”。运行模式只读快照，修改跳转草稿副本。危险动作显示实际影响：暂停后在途仍运行、取消可能有已发生操作。历史页展示revision与attempt选择，不将历史回放称为重新执行。

完整产品还将加入 Agent 库、真实审批和运行事件时间线。这些功能属于后续联调，当前浏览器画布可独立编辑 TEST 草稿。
