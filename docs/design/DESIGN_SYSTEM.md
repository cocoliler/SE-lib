# 设计系统
## Tokens（CSS变量规范）
| Token | 值 / 用途 |
|---|---|
| --bg | #F5F7FA 画布和工作台 |
| --surface | #FFFFFF 面板/节点 |
| --text | #182230 主要文字 |
| --text-muted | #475467 辅助说明 |
| --border | #D0D5DD 细边 |
| --primary | #2563EB 操作与选中 |
| --danger | #B42318 错误 |
| --warning | #92400E 待确认 |
| --success | #067647 校验通过（不是任务执行成功） |

字体 system-ui、Segoe UI、Microsoft YaHei、sans-serif；正文14px/22px，辅助12px/18px，卡片标题14px/20px semibold，页面标题20px/28px。
间距4/8/12/16/24/32px；输入与按钮高36px，工具按钮36×36；圆角面板12px、按钮8px；阴影仅浮层/选中需要。
主要按钮每区域最多一个，次操作用中性描边；图标必须有aria-label和悬停说明；不得用颜色作为唯一状态。

## 节点视觉
任务卡默认宽240px、最小高88px，标题最多两行，下排“阶段·角色·优先级”，右上校验问题数；依赖数量在详情显示。
左输入、右输出，视觉端点10px、交互命中24px。hover显示端点，键盘焦点同样可见。选中蓝边2px，错误红边+图标，非错误节点不整块高饱和填色。
连线1.5px灰色、明确箭头；选中蓝色；错误红色虚线附文本提示。不在计划边持续流动动画，避免暗示真实执行。
阶段背景浅灰虚线边框，标题与任务卡区分；注释淡黄，明确“注释”标签。

## 可访问性
所有交互可Tab到达；焦点2px外环，Esc关闭详情并回原触发按钮。普通文字对比目标≥4.5:1，图形与焦点≥3:1，实施时自动测量。
输入框编辑时不触发Delete画布快捷键。任务列表提供完整等价操作；连线可在详情“添加上游任务”完成，不强制鼠标拖拽。
加载区使用aria-live=polite，减少动画遵守prefers-reduced-motion。缩放不缩小全局工具文字。
