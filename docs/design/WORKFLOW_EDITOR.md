# 可视化编排器

## 当前前端实现

| 操作 | 行为 |
|---|---|
| 项目需求 | 输入、填入示例与加载固定 TEST 计划。替换前确认，保留填写的需求 |
| 手动添加节点 | 点击左侧「+」新建任务并打开详情。通过节点输出端和输入端连接依赖 |
| 连线校验 | 拦截自环、重复和循环依赖，显示原因。可在右侧移除上游依赖 |
| 添加注释 | 创建仅用于标记画布的注释卡片，可移动、编辑和删除，不进入任务计划或参与执行 |
| 选择与手形平移 | 选择模式可移动节点、编辑连线。手形模式拖动空白处平移，禁用节点拖动与连线 |
| 整理节点 | 按 DAG 依赖深度从左到右排列任务，同层纵向排列，注释放在任务下方。整理只改变坐标 |
| 导出 PNG | 下载包含任务、依赖连线和注释的完整画布图，范围随节点边界计算 |
| 本地草稿 | 保存需求、计划、坐标和注释到当前浏览器，刷新后恢复，兼容不含需求或注释的旧草稿。修改后离开页面时使用浏览器确认提示 |

前端示例沿用 Python 原型的 `tasks[].{id,title,depends_on}`，草稿中的坐标和注释与任务计划分开保存。当前整理使用按依赖分层排布。前端生产构建和 Chrome 验证已覆盖画布操作、注释恢复、手形平移与 PNG 下载。启动和试用步骤见[前端说明](../../frontend/README.md)。

## 完整产品设计目标

画布数据投影自TaskSpec和三种关系，React Flow node.id=task_id；positions/group/viewport写layout，业务definition不包含React组件属性。禁止toObject直接作为运行配置；服务端校验是最终权威。

智能规划结果进入独立候选revision，批准合并才成为草稿；AI优化patch携base_revision，冲突返回409并展示差异。手动新增/连线/条件/权限编辑与智能结果使用同一数据模型。保存expected_revision CAS；运行冻结快照。撤销仅作用未发布草稿，不能撤销已发生执行。

拖动/框选、多选复制、删除、分组、缩放、小地图、适配、键盘导航。一次拖动记一个历史操作；自动布局为一次可撤销命令。复制重新生成ID并重映射内部binding，外部引用明确提示；删除显示依赖影响，不能静默清空必需输入。文本编辑时快捷键不触发图删除。

连接前检查方向/类型/自环，完成连线后检查循环；依赖、data binding与handoff关系分别建模。新增data binding必须已有依赖祖先路径，否则提示补建依赖并原子提交；handoff不能绕过任务依赖。条件编辑器使用字段选择与白名单比较器，不能输入脚本。

Dagre用于P0 DAG布局，视觉分组先折叠为超节点再组内布局，不承诺复杂跨组边最优；分组不改变调度、P0不嵌套。自动布局保留用户锁定位置，若约束冲突给出选择。实时状态按run/task/attempt映射，当前草稿不能消费旧run事件覆盖节点配置。

验收目标（未实测）：100节点/200依赖边拖动30fps以上；保存p95<500ms，已落库状态至UI p95<500ms（本机4核16GB SSD）。显示层节流不会丢状态，大文本只在详情按需加载。配合UI测试验证缩放后handles、分组连线和焦点顺序。
