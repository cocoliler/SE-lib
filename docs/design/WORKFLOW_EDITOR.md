# 工作流编辑器
## 已有实现与保留
现有 main.tsx/plan.ts/canvas-tools.ts 已有固定TEST计划、任务添加、连线检查、注释、选择/手形平移、拓扑分层整理、PNG和localStorage草稿。
本轮只更新设计，不重新声明这些操作经过本轮浏览器测试。业务字段仍只有id/title/depends_on，须增加契约适配。
P0继续使用现有布局算法，不强制引入Dagre；复杂布局、撤销重做和阶段折叠为P1。

## 图投影
TaskNode.id=task_id；edges按dependencies派生。Note与StageGroup仅存Layout。节点类型注册在组件外，稳定memo/callback，避免拖动时重建全部组件。
业务编辑独立draft store；layout store只管理positions/viewport/notes；selection属于临时UI状态。
StageGroup只表达stage，不自动影响拓扑；没有业务需要不画可执行START/END，多个根可并列。

## 操作规则
| 操作 | 行为 / 数据影响 |
|---|---|
| 添加任务 | 新稳定ID，打开详情；未补交付/验收/角色则草稿invalid |
| 添加注释 | 点击画布落点，只改layout，不进入导出业务tasks |
| 连线 | 输出→输入；先查自环/重复/回路，提交后服务端完整校验；不能借连线自动创建输入绑定 |
| 添加输入绑定 | 选task+deliverable；缺直接依赖则提示并原子补边；不允许跨计划 |
| 删除任务 | 展示受影响依赖和输入引用；用户明确删除关系/改引用，否则阻止保存 |
| 手形平移 | 拖空白平移，禁节点拖动/连线；空格临时手形，松开恢复 |
| 整理节点 | 按拓扑层从左到右；只改坐标，处理注释；不重新请求模型 |
| 缩放/小地图 | 0.25–2范围建议；适配全部任务或当前选中 |
| 校验定位 | 点击Issue，fit到目标并聚焦详情字段；多个环边共同高亮 |
| 导出PNG | 包含画布范围、版本与TEST水印（如果来源为TEST）；不替代JSON契约 |
| 保存 | 合法候选→新PlanRevision；layout单独保存；明确本地草稿与数据库已保存 |
| 历史查看 | 禁止修改/连线；允许缩放、平移、看详情与导出 |

P1撤销记录一次拖动/布局为一个命令；最多100个操作，只有草稿可撤销；保存后历史仍保留，不撤销服务器事务。
P1阶段折叠用视觉代理边，展开还原实际任务关系；JSON导出不存代理边。
旧本地草稿导入先备份原localStorage值，适配后提示新增必填字段，失败不覆盖原稿。没有需求出处的旧固定示例不可标AI有效计划。

## 性能
限制卡片内容，长描述只在详情加载；订阅按task_id，业务验证在动作结束触发；图规模目标及测量见质量属性。
大型图优先列表/筛选，分组折叠需测后引入。PNG对超大位图边界设置上限并提示，不能为导出卡住主界面。
